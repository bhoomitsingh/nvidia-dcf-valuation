## Project Overview

This project presents a Discounted Cash Flow (DCF) valuation of **NVIDIA Corporation (NASDAQ: NVDA)** using the **Free Cash Flow to Firm (FCFF)** methodology. The model forecasts NVIDIA's financial performance, estimates future free cash flows, calculates the Weighted Average Cost of Capital (WACC), and derives an intrinsic value per share.

The objective of this project is to demonstrate practical financial modeling, valuation, and advanced Microsoft Excel skills through a structured equity valuation model.

---

## Project Objectives

* Build a structured DCF valuation model in Microsoft Excel
* Forecast NVIDIA's future financial performance
* Estimate Enterprise Value and Equity Value
* Calculate Intrinsic Value per Share
* Perform sensitivity analysis using WACC and Terminal Growth Rate
* Present valuation results through a dashboard

## Valuation Methodology

The model follows the **Free Cash Flow to Firm (FCFF)** approach.

### Workflow

1. Historical Financial Statement Analysis
2. Revenue Forecasting
3. Operating Profit Forecast
4. Free Cash Flow Forecast
5. WACC Calculation
6. Terminal Value Estimation
7. Enterprise Value Calculation
8. Equity Value Calculation
9. Intrinsic Share Price Estimation

---

## Key Assumptions

| Assumption           | Value |
| -------------------- | ----: |
| Risk-Free Rate       |  4.3% |
| Equity Risk Premium  |  5.5% |
| Beta                 |  1.80 |
| Cost of Debt         |  3.8% |
| Tax Rate             | 15.0% |
| Terminal Growth Rate |  3.0% |
| Approximate WACC     | 12.5% |

> **Note:** These assumptions are based on publicly available information and reasonable valuation assumptions for educational purposes.
